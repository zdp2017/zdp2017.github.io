Python 是智能体（Agent）开发的主力语言——主流 Agent 框架、大模型 SDK、数据与工具链，几乎都以 Python 为第一公民。这个板块用来沉淀我从"会写基础语法"到"能独立支撑一个智能体工程"过程中的全部 Python 笔记。

## 这个板块会放什么

- 语法与语言特性速查：装饰器、迭代器、生成器、异步编程
- 工程化必备：虚拟环境、依赖管理、项目结构、类型注解
- 常用库实战：requests、pydantic、asyncio、pytest
- 与大模型 / Agent 相关的小工具与脚本

## 怎么用

1. 先用语法速查建立自己的"索引"；
2. 再按需做小练习，练习代码随文章一起留档；
3. 踩过的坑单独开一篇"踩坑记录"，方便回查。

不用追求看完所有文章，把这个板块当成**自己的 Python 手册**：用到什么查什么、学了什么写什么。

> 写在前面：本站主线是从零走向智能体架构师，Python 只是工具。别沉迷语法本身，够用就继续往前走。
