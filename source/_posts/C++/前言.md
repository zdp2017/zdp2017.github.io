C++ 是 AI 世界"性能那半边"的通用语言：推理引擎、算子库、量化工具、高性能服务，几乎都绕不开它。Agent 架构师不一定天天写 C++，但能看懂它、能改它，在性能问题面前就不会被人"忽悠"。

## 这个板块会放什么

- 语言核心：指针 / 引用、内存模型、STL、现代 C++（11/17/20）
- 与 Python 对照学习：同一个问题，两种写法差在哪
- AI 相关 C++ 实践：推理引擎、算子、量化的入门阅读
- 构建工具与工程：CMake、编译、链接基础

## 怎么用

主线仍是 Python / Agent，C++ 按"够用"原则推进：先能读懂推理引擎的代码脉络，再谈自己动手优化。

> 给 Python 背景的人一句话：C++ 难不在语法，而在你要时刻想着"内存和性能"；反过来，这恰好帮你理解 Python 解释器替你扛了多少事。
